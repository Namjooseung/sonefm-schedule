# SoneFM 편성표 — 문제 해결

문제가 생기면 먼저 아래 표를 확인합니다. 해결되지 않으면 `문서\SoneFM\logs\app.log` 파일을 개발자에게 보내 주세요.

| 증상 | 원인 | 해결 |
|---|---|---|
| 아이콘을 눌러도 창이 안 뜨고 "프로그램을 시작하지 못했습니다" 메시지가 나옴 | 데이터 파일을 열거나 고치는 중 오류 | `logs\app.log` 맨 아래를 확인합니다. 데이터 파일이 손상됐다면 `backups` 폴더의 최근 백업으로 되돌립니다 (아래 "백업에서 되돌리기"). |
| "화면 파일을 찾지 못했습니다" 메시지 | 설치 파일 일부가 빠짐 | 프로그램을 다시 설치합니다. 데이터는 지워지지 않습니다. |
| 창이 하얗게만 뜨고 아무것도 안 나옴 | Microsoft Edge WebView2 런타임이 없음 | 마이크로소프트 홈페이지에서 "WebView2 Runtime"을 내려받아 설치한 뒤 다시 실행합니다. |
| 화면에 "프로그램 내부와 연결하지 못했습니다"가 나옴 | 화면과 내부 프로그램 연결 실패 | 프로그램을 완전히 닫고 다시 실행합니다. 반복되면 로그 파일을 개발자에게 보냅니다. |

## 백업에서 되돌리기 (임시 방법)

보통은 설정 화면 → 백업 → "이 백업으로 되돌리기"를 씁니다. 프로그램이 아예 켜지지 않을 때만 아래처럼 직접 합니다.

1. 프로그램을 닫습니다.
2. `문서\SoneFM\data\schedule.db` 파일 이름을 `schedule_고장.db`로 바꿔 둡니다.
3. `문서\SoneFM\backups\`에서 되돌리고 싶은 날짜의 파일을 복사해 `data` 폴더에 붙여 넣고, 이름을 `schedule.db`로 바꿉니다.
4. 프로그램을 다시 켭니다.

## 프로그램 화면에서 자주 보는 안내

| 안내 문구 | 뜻 | 할 일 |
|---|---|---|
| "'○○'은(는) 이미 '△△'의 이름이나 별칭으로 쓰이고 있습니다." | 이름이나 별칭이 다른 프로그램과 같습니다. 엑셀을 가져올 때 헷갈리지 않도록 막습니다. | 이름이나 별칭 중 하나를 다르게 바꿉니다. |
| "○ ○시 자리가 적용 기간이 겹칩니다." | 같은 요일·시각 자리가 두 줄 있고 기간이 겹칩니다. | 한 줄의 적용 종료일을 다른 줄의 시작일 전날로 맞춥니다. 시간 변경이라면 "개편" 버튼을 씁니다. |
| "이미 편성표에 쓰인 편성 자리는 지울 수 없습니다." | 그 자리로 만든 편성표 칸이 있습니다. | 삭제 대신 적용 종료일을 넣습니다. |
| "편성표에 이미 쓰인 프로그램은 지울 수 없습니다." | 기록 보존을 위해 막습니다. | 종영 처리합니다. |

## 엑셀 내보내기·가져오기

| 증상 | 원인 | 해결 |
|---|---|---|
| "파일을 저장할 수 없습니다" | 같은 이름의 파일이 엑셀에 열려 있음 | 엑셀에서 그 파일을 닫거나 다른 이름으로 저장합니다. |
| "xlsx 형식의 엑셀 파일만…" | 예전 xls 파일 | 엑셀에서 열고 "다른 이름으로 저장 → Excel 통합 문서(*.xlsx)"로 저장한 뒤 다시 가져옵니다. |
| 가져온 뒤 회차가 엑셀과 다른 칸이 있음 | 엑셀에서 회차를 건너뛰었거나, 이름 표기가 달라 다른 프로그램으로 잡힘 | 이름이면: 백업으로 되돌린 뒤 "엑셀의 다른 이름과 같음"으로 묶어 다시 가져옵니다. 회차 건너뜀이면: 해당 재방 칸에서 "재방 회차 지정"으로 맞춥니다. |
| 다음 달을 생성했는데 일부 프로그램이 안 나옴 | 가져올 때 추정한 편성 자리가 없거나 틀림 | 프로그램 화면에서 그 프로그램의 편성 자리를 확인·추가한 뒤 다시 생성합니다. |
| 가져오기 결과에 "수식 오류(#REF!) 칸" | 원본 엑셀의 수식이 깨진 칸 | 그 칸은 빈칸으로 남습니다. 편성표에서 칸을 눌러 채웁니다. |


## 데이터 파일·백업

| 증상 | 원인 | 해결 |
|---|---|---|
| "SoneFM 편성표 데이터 파일이 아닙니다" | 다른 프로그램의 파일이나 손상된 파일을 고름 | 백업 폴더의 `schedule_날짜_시각_….db` 파일이나 "데이터 내보내기"로 만든 .db 파일을 고릅니다. |
| "더 새 버전의 프로그램에서 만든 데이터 파일" | 새 버전 앱에서 만든 파일을 옛 버전에서 엶 | 이 PC의 프로그램을 최신 설치 파일로 업데이트합니다. |
| "그 폴더에 이미 schedule.db가 있습니다" | 옮길 폴더에 데이터 파일이 이미 있음 | 그 파일을 쓰려면 "그 폴더의 데이터 쓰기", 아니면 다른 폴더를 고릅니다. |
| 되돌리기를 잘못 했다 | — | 백업 목록에서 `before-restore`가 붙은 가장 최근 파일로 다시 되돌립니다. |

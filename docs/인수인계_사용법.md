# SoneFM 편성표 — 사용법

이 문서는 개발자가 아닌 분이 프로그램을 쓰고 관리할 수 있도록 적은 안내서입니다. 기능이 추가될 때마다 이어서 적습니다.

## 1. 설치·실행·업데이트·제거

### 설치
1. `SoneFM편성표_Setup.exe`를 더블클릭합니다. (관리자 권한이 없어도 설치됩니다.)
2. **"Windows의 PC 보호" 파란 창이 뜨면**: 개인이 만든 프로그램이라 처음 실행할 때 윈도우가 막는 것입니다.
   - 창 안의 **추가 정보**를 누르고 → 아래에 생긴 **실행** 버튼을 누릅니다.
3. "바탕화면에 아이콘 만들기"를 체크한 채 **다음 → 설치**를 누릅니다.
4. "이 PC에 Microsoft Edge WebView2 런타임이 없습니다"라는 안내가 뜨면, 설치를 마친 뒤 마이크로소프트 홈페이지에서 "WebView2 Runtime"을 검색해 "Evergreen 부트스트래퍼"를 설치합니다. (윈도우 10/11 대부분은 이미 있어서 이 안내가 뜨지 않습니다.)

### 실행
- 바탕화면(또는 시작 메뉴)의 **SoneFM 편성표** 아이콘을 더블클릭합니다.
- 창 제목이 "SoneFM 편성표"인 창이 뜨면 정상입니다.

### 업데이트 (새 버전 설치)
- 새 설치 파일을 받아 그냥 실행하면 됩니다. 기존 프로그램을 지우지 않아도 덮어서 설치됩니다.
- 편성 데이터는 `문서\SoneFM`에 따로 있어서 **업데이트해도 그대로 남습니다.** 새 버전이 데이터 구조를 바꿔야 하면 바꾸기 직전에 자동으로 백업합니다.

### 제거
- 윈도우 **설정 → 앱 → 설치된 앱**에서 "SoneFM 편성표"를 찾아 **제거**합니다.
- 제거해도 `문서\SoneFM` 폴더(데이터·백업·로그)는 남습니다. 완전히 지우려면 그 폴더를 직접 지웁니다.

### 다른 PC로 옮기기
1. 지금 PC: 설정 → 데이터 파일 → **데이터 내보내기** → .db 파일을 USB 등에 저장
2. 새 PC: 설치 파일로 설치 → 실행 → 설정 → **데이터 가져오기** → 그 .db 파일 선택

## 2. 데이터는 어디에 저장되나요?

프로그램을 지우거나 새 버전으로 다시 설치해도 아래 폴더의 데이터는 그대로 남습니다.

| 무엇 | 위치 |
|---|---|
| 편성 데이터 (파일 하나) | `문서\SoneFM\data\schedule.db` |
| 자동 백업 | `문서\SoneFM\backups\` |
| 오류 기록 (문제가 생겼을 때 개발자에게 보낼 파일) | `문서\SoneFM\logs\app.log` |
| 기본 설정 (데이터 위치·백업 폴더·백업 개수) | `문서\SoneFM\config.json` |

## 3. 자동 백업

- 프로그램을 **켤 때마다** 편성 데이터를 `backups` 폴더에 복사해 둡니다.
  - 파일 이름 예: `schedule_20261103_151908_startup.db` (2026년 11월 3일 15시 19분 08초에 켤 때 만든 백업)
- 최근 **30개**만 남기고 오래된 백업은 자동으로 지웁니다.
- 프로그램이 새 버전으로 바뀌어 데이터 구조를 고칠 때도, 고치기 직전에 따로 백업합니다 (`_before-v2` 같은 이름).

## 4. 프로그램 등록·관리 (왼쪽 메뉴 "프로그램")

화면 왼쪽은 프로그램 목록, 오른쪽은 고른 프로그램의 상세 정보입니다.

### 새 프로그램 등록
1. **새 프로그램**을 누릅니다.
2. 이름, 분야(교양/오락), 청취자 참여 여부, 제작 주체를 넣습니다.
3. **방송 주기**를 고릅니다.
   | 주기 | 언제 쓰나요 | 추가로 넣을 것 |
   |---|---|---|
   | 매주 | 매주 같은 요일·시각에 본방 | — |
   | 격주 | 2주에 한 번 본방 | **기준일**: 본방이 나가는 주의 아무 날짜 하나 |
   | 주 n회 | 일주일에 여러 번 본방 | 편성 자리를 요일마다 하나씩 |
   | 매월 n째 주 | 한 달에 한 번 | 몇째 주인지 |
   | 비정기 | 본방 날짜가 정해져 있지 않음 | 편성표에서 본방 나가는 날 칸을 "본방으로" 바꿉니다 |
   | 단발(특집) | 한 번만 나가는 특집 | 편성 자리 없음 |
   - 격주·매월 n째 주는 "방송 없는 주의 본방 자리"를 재방으로 채울지 비울지 고를 수 있습니다. 보통은 "설정 기본값 따름"으로 둡니다.
4. **시작 회차**: 이 앱에서 처음 계산할 회차입니다. 예를 들어 지금까지 40화가 나갔다면 41을 넣습니다.
5. **편성 자리**: **자리 추가**를 눌러 요일, 시각, 본방/재방, 적용 시작일을 넣습니다. 재방 자리도 여기에 함께 넣습니다.
6. **별칭**: 기존 엑셀 편성표에 다르게 적혔던 이름(예: 줄임말)을 넣고 Enter를 누릅니다. 나중에 엑셀을 가져올 때 같은 프로그램으로 알아봅니다.
7. **저장**을 누릅니다. 빠진 값이 있으면 빨간 상자에 이유가 나옵니다.

### 시간이 바뀌었을 때 (개편)
프로그램을 새로 만들지 말고 편성 자리 줄의 **개편**을 누릅니다.
1. 새 편성이 시작되는 날짜를 고르고 **개편 줄 만들기**를 누릅니다.
2. 기존 줄은 그 전날까지로 닫히고, 같은 내용의 새 줄이 생깁니다.
3. 새 줄에서 바뀐 요일·시각을 고친 뒤 **저장**합니다.

이렇게 해야 회차가 끊기지 않고 이어집니다.

### 종영
1. 프로그램을 고르고 아래쪽 **종영 처리**를 누릅니다.
2. 마지막 방송일(종영일)을 고르고 **종영 처리**를 누릅니다. 방송 중인 편성 자리도 그날로 함께 닫힙니다.
3. 종영한 프로그램은 목록에서 숨겨집니다. 다시 보려면 목록 위의 **종영 포함**을 켭니다.
4. 잘못 종영했다면 **종영 취소**를 누릅니다. 닫힌 편성 자리는 필요하면 새로 추가합니다.

### 삭제
- 잘못 등록한 프로그램만 **삭제**합니다. 편성표에 한 번이라도 쓰인 프로그램은 삭제되지 않으니 종영 처리해 주세요.

### 특집 빠른 등록
- 목록 위의 **특집 등록**을 누르고 이름, 분야, 청취자 참여 여부만 넣으면 됩니다.
- 특집이 정규 프로그램이 되면, 그 특집을 골라 주기를 바꾸고 편성 자리를 추가해 저장합니다.

### 저장하지 않고 다른 프로그램을 누르면
"저장하지 않은 변경이 있습니다"라는 노란 상자가 나옵니다. **계속 편집**을 눌러 저장하거나, **저장하지 않고 이동**을 누릅니다.

### 고정 편성 (굿모닝!, 굿바이!)
- 프로그램 목록에 **굿모닝!**(매일 06시)과 **굿바이!**(매일 22시)가 처음부터 들어 있습니다. 매일 고정으로 나가는 프로그램이라 지우지 마세요.
- 시간이 바뀌면 다른 프로그램처럼 편성 자리의 **개편**으로 고칩니다.

### 회차는 어떻게 정해지나요?
- 회차는 저장해 두는 값이 아니라 편성표를 보고 매번 계산합니다.
  - 본방: 시작 회차부터 본방이 나갈 때마다 1씩 올라갑니다. 결방된 주는 세지 않아서 다음 본방이 그 회차를 이어받습니다.
  - 재방: 바로 전에 나간 본방의 회차를 따라갑니다.
- 격주 프로그램이 쉬는 주에는 그 자리에 직전 회차 재방이 들어갑니다. (예: 75화 → 75화 재방 → 76화)
- 시작 회차를 41로 넣으면 40화까지는 이미 나간 것으로 봅니다.

## 5. 편성표 만들기 (왼쪽 메뉴 "편성표")

### 화면 보는 법
- 맨 위: 연도와 1~12월. 달을 누르면 그 달로 이동합니다. 확정·마감된 달은 달 이름 옆에 작게 표시됩니다.
- 한 줄 = 한 주(월~일)입니다. 줄 왼쪽 위의 `1주`는 그 달의 몇째 주, `45주차`는 1년 중 몇째 주(국제 기준)입니다.
- **주는 월요일이 속한 달에 들어갑니다.** 예를 들어 10/26(월)~11/1(일) 주는 10월 화면에서 편집합니다.
  - 11월 화면 맨 위에는 10월 마지막 주가 접힌 채로 있습니다(참고용). 주 이름을 누르면 펼쳐지고, 고치려면 "10월에서 편집"을 누릅니다.
  - 11월 마지막 주에 들어 있는 12월 날짜는 흐리게 보입니다.
- 칸 색: 교양은 하늘색, 오락은 노란색, 특집은 보라색입니다. 본방 자리는 진하게, 재방 자리는 연하게 표시되고 재방 자리에는 `재` 표시가 붙습니다.
- **프로그램명이 빨간색이면 그날 회차가 올라간 칸(새 본방)입니다.** 진한 칸인데 이름이 검은색이면 본방 자리에 직전 회차가 다시 나가는 날입니다(격주 쉬는 주 등). 963 음악쌀롱처럼 회차가 없는 프로그램은 빨간색으로 표시하지 않습니다.
- 굿모닝!·굿바이!는 한 주 전체를 가로지르는 회색 띠로 보입니다.
- 빨간 칸 **본방 대기**: 아직 본방이 한 번도 안 나간 신규 프로그램의 재방입니다.
- 굵은 테두리 칸: 사람이 직접 고친 칸입니다.
- **기본/압축**: 압축을 누르면 칸 높이가 낮아져 한 화면에 더 많이 보입니다. 이 PC에서 고른 값을 기억합니다.

### 새 달 만들기 (버튼 두 번)
1. 새 달을 열면 비어 있습니다.
2. **첫 주 불러오기**: 프로그램 화면에 등록한 편성 자리와 주기대로 첫 주가 채워집니다.
3. 첫 주를 보고 개편 사항이 있으면 프로그램 화면에서 편성 자리를 고칩니다.
4. **월단위 생성**: 나머지 주가 채워집니다. 격주·비정기 프로그램은 주마다 다시 판정하므로 첫 주를 그대로 복사하지 않습니다.
5. 다시 눌러도 괜찮습니다. 바뀐 규칙만 반영됩니다.
   - 사람이 직접 고친 칸은 그대로 둡니다. 규칙과 다르면 "직접 수정한 칸이 있습니다" 창에 목록이 나오고, **덮어쓰기**를 눌러야만 바뀝니다.
6. 같은 칸에 두 프로그램이 겹치면 오른쪽 **확인할 것**에 "편성 자리 충돌"이 나옵니다. 누르면 그 칸으로 이동합니다. 프로그램 화면에서 한쪽 자리를 고칩니다.

### 오른쪽 패널
- **총 방송**: 그 달 달력 날짜(1일~말일)에 채워진 칸 × 60분. 기준은 일수 × 17시간 × 60분입니다.
- 패널은 **패널 닫기/열기**로 접을 수 있습니다.

## 6. 칸 고치기 (편성표에서 칸을 누르기)

칸을 누르면 옆에 작은 창(칸 팝업)이 뜹니다. 창 밖을 누르거나 Esc를 누르면 닫힙니다.

| 하고 싶은 일 | 누를 것 | 결과 |
|---|---|---|
| 이번 주만 다른 프로그램 내보내기 | **다른 프로그램으로 교체** → 프로그램 고르기 → 본방/재방 → **이번만** | 원래 프로그램은 그날 자동으로 결방 처리되고, 다음 본방이 그 회차를 이어받습니다. |
| 이 날짜부터 계속 다른 프로그램 (개편) | 같은 순서로 → **이후 전부** | 프로그램 화면의 편성 자리도 함께 바뀌고, 이미 만든 뒤쪽 칸도 다시 맞춰집니다. |
| 본방 대신 재방 (또는 반대) | 위쪽 **본방 / 재방** 버튼 | 정규 프로그램은 "이번만 / 이후 전부"를 고릅니다. 비정기 프로그램은 그 칸만 바뀝니다. |
| 결방 | **결방** → 사유(선택) → **재방으로 대체** 또는 **비워두기** | 결방한 본방은 회차에 세지 않습니다. |
| 특집 | **특집 넣기** → 새 특집 이름 입력 또는 예전 특집 고르기 | 원래 프로그램은 그날 결방 처리됩니다. |
| 회차 고치기 | 칸 팝업의 **회차 − / +** 버튼 | 본방 칸을 고치면 다음 본방이 그 번호부터 이어집니다. 재방 칸은 그 칸만 바뀝니다(앙코르 등). **자동**을 누르면 계산값으로 돌아갑니다. |
| 당일 사고·긴급 결방 기록 | **실제 변경 기록** | 편성(계획)은 그대로 두고 메모만 남깁니다. 칸에 주황 삼각형이 붙습니다. |
| 송출 파일 받았는지 표시 | **송출 파일**: 미입고 / 입고 / 송출 완료 | 칸 이름 앞 초록 점 = 입고, 회색 점 = 송출 완료 |
| 고친 것 취소 | **원래대로 되돌리기** | 편성 자리대로 돌아가고 결방 기록도 지워집니다. |
| 빈칸 채우기 | 빈칸을 누르고 **프로그램 넣기** 또는 **특집 넣기** | |

- 굿모닝!·굿바이! 띠를 누르면 날짜를 고르는 창이 뜹니다. 고른 날 칸만 위 방법으로 바꿀 수 있습니다.
- 칸 오른쪽 작은 그림: ⇄ 교체, ☆ 특집, ↻ 결방 후 재방 대체, △ 실제 변경 있음.

### 되돌리기와 변경 기록
- **Ctrl+Z** 또는 위쪽 **되돌리기**: 방금 한 일을 하나씩 되돌립니다. 프로그램을 껐다 켜면 그 전 작업은 되돌릴 수 없습니다. 그때는 **원래대로 되돌리기**나 백업을 씁니다.
- **변경 기록**: 언제 무엇을 바꿨는지 최근 200건을 보여줍니다.

### 주 접기
- 주 이름(`1주` 등)을 누르면 그 주가 접히고 다시 누르면 펼쳐집니다. 위쪽 **모두 접기 / 모두 펼치기**도 있습니다. 이 PC에서 접어 둔 상태를 기억합니다.

## 7. 확인할 것(검증)과 확정·마감

### 오른쪽 "확인할 것"
그 달 달력 날짜(1일~말일) 기준으로 자동 점검합니다. 항목을 누르면 그 칸으로 이동합니다.

| 항목 | 색 | 뜻 |
|---|---|---|
| 빈칸 | 빨강 | 06~22시 중 비어 있는 칸 (날짜별로 묶어 보여줌) |
| 총 방송분 | 빨강 | 채워진 칸 × 60분이 기준(일수 × 17 × 60분)에 못 미침 |
| 본방 대기 | 빨강 | 신규 프로그램의 첫 본방 전 재방 |
| 고아 예외 | 주황 | 결방 기록이 있는데 개편으로 원래 자리가 없어짐 → 칸을 열어 "원래대로" |
| 편성 자리 충돌 | 주황 | 같은 칸에 두 프로그램이 겹침 → 프로그램 화면에서 자리 조정 |

- 11/1처럼 앞 달 소속 주에 있는 날짜는 "(10월 화면에서 고칩니다)"라고 나오고, 누르면 그 달 화면으로 이동합니다.
- 법정 편성비율 경고는 기준값이 정해지면 추가합니다.

### 월 상태: 작성 중 → 확정 → 마감
- 제목 옆 버튼으로 바꿉니다.
- **확정**: 편성이 끝났다는 표시입니다. 확정 후에도 고칠 수 있지만 변경 기록에 "[확정 후 변경]"이 붙습니다. **확정 취소**로 작성 중으로 돌릴 수 있습니다.
- **마감**: 보고서를 낸 달. 칸 편집과 다시 생성이 잠깁니다.
- **잠금 해제**: 마감을 풀 때는 사유를 꼭 적어야 하고, 변경 기록에 남습니다. 풀면 확정 상태가 됩니다.
- 마감된 달보다 앞선 칸을 바꿔서 마감 달의 회차가 달라질 수 있으면 주황 알림이 뜹니다. 제출한 보고서와 다르지 않은지 확인합니다.

## 8. 엑셀 내보내기·가져오기

### 엑셀로 내보내기 (매달)
1. 편성표 화면에서 내보낼 달로 이동합니다.
2. 그리드 위 **엑셀 내보내기** → 저장할 위치와 이름을 고릅니다. (기본 이름: `SoneFM편성표_2026년11월.xlsx`)
3. 기존 엑셀 편성표와 같은 모양으로 저장됩니다. **수식 없이 글자만** 들어 있어 어디에 붙여 넣어도 깨지지 않습니다.
   - 본방 `프로그램_23화`, 재방 `프로그램_23화(재)`, 회차를 안 붙이는 프로그램은 이름만 들어갑니다.
   - 06시·22시 굿모닝!/굿바이! 줄은 예전 양식처럼 가로로 합쳐 비워 둡니다.
   - 주 머리글 `11-45`의 45는 1년 중 몇째 주(국제 기준)입니다.
- 회차를 붙일지는 프로그램 화면의 **회차 표시** 체크로 정합니다. (예: 963 음악쌀롱은 끔)

### 기존 엑셀 편성표 가져오기 (처음 한 번)
설정 화면 아래쪽 **기존 엑셀 편성표 가져오기**에서 합니다. 가져오기 전에 지금 데이터를 자동으로 백업합니다.
1. **엑셀 파일 고르기** → 시트 목록이 나옵니다. 이름이 `2611`처럼 연월(YYMM)인 시트만 가져올 수 있습니다. 가져올 달을 체크합니다.
2. **이름 연결**: 엑셀에 적힌 이름마다 정합니다.
   - **새 프로그램으로 등록**: 분야(교양/오락)와 청취자 참여를 고릅니다. "연결 안 된 이름 모두 새로 등록"으로 한꺼번에 정할 수 있습니다.
   - **기존 프로그램에 연결**: 그 이름이 별칭으로 추가됩니다. "추천" 표시는 띄어쓰기만 다른 이름입니다.
   - **엑셀의 다른 이름과 같음**: `그삶이다`와 `그 삶이다`처럼 표기만 다른 이름을 하나로 묶습니다. 묶어야 회차가 이어집니다.
   - **가져오지 않음**: 그 이름의 칸은 비워 둡니다.
3. **가져오기** → 결과를 확인합니다.
   - 엑셀에서 본방 자리에 같은 회차를 다시 적은 칸(`(재)` 없이)은 재방으로 들어옵니다.
   - 회차는 가장 최근 본방에 맞춥니다. 지난 달 일부 칸은 엑셀과 회차가 다를 수 있고, 그 목록이 결과에 나옵니다.
4. 새로 등록된 프로그램은 마지막 4주를 보고 편성 자리와 주기(매주/격주/비정기)를 추정해 넣었습니다. **프로그램 화면에서 꼭 확인**해 주세요. 마지막 4주에 나오지 않은 프로그램은 종영 처리되어 있습니다(목록에서 "종영 포함"을 켜면 보임).
- 가져온 칸에 마우스를 올리면 "엑셀에서 가져온 칸"이라고 나옵니다. 월단위 생성을 다시 눌러도 지워지지 않습니다.
- 잘못 가져왔다면 설정의 백업 폴더(`문서\SoneFM\backups`)에 있는 `..._before-import.db`로 되돌립니다. (문제해결 문서의 "백업에서 되돌리기" 참고)

### 재방 표시 규칙
- 재방 칸에는 이름 옆에 `재` 표시가 붙습니다(엑셀에서는 이름 뒤 `(재)`).
- 단, **원래 본방 자리에 나가는 재방**(격주 프로그램이 쉬는 주, 휴방 기간 등)에는 표시를 붙이지 않고 칸도 진한 색 그대로입니다. 이름이 빨간색이 아닌 것으로 구분하고, 회차 계산에서는 재방으로 셉니다. 마우스를 올리면 "재방(본방 자리)"로 나옵니다.


## 9. 설정 화면

### 편성 규칙
- **방송 없는 주의 본방 자리**: 격주·매월 n째 주 프로그램이 쉬는 주에 그 자리를 직전 회차 재방으로 채울지(기본) 비울지. 프로그램마다 따로 정할 수도 있습니다(프로그램 화면).
- **고정 편성**: 편성표에서 가로 띠로 보이고 회차를 숨기는 프로그램(기본 굿모닝!·굿바이!).
- 바꾼 뒤 **저장**을 누릅니다. 이미 만든 달에 반영하려면 편성표에서 월단위 생성을 다시 누릅니다.

### 임시공휴일
- 법정 공휴일은 자동으로 표시됩니다. 정부가 갑자기 정한 임시공휴일처럼 빠진 날만 날짜와 이름을 넣어 **추가**합니다.

### 데이터 파일
- **위치 바꾸기**: 데이터 파일을 다른 폴더로 옮깁니다.
  - **복사해서 옮기기**: 지금 데이터를 새 폴더로 복사하고 앞으로 그 파일을 씁니다. 예전 파일은 그대로 남습니다.
  - **그 폴더의 데이터 쓰기**: 새 폴더에 이미 있는 schedule.db(다른 PC에서 쓰던 파일 등)를 씁니다.
- **데이터 내보내기 / 가져오기**: 다른 PC로 옮길 때 씁니다. 이 PC에서 내보낸 .db 파일을 새 PC에서 가져옵니다. 가져오기 전 데이터는 자동으로 백업됩니다.

### 백업
- 프로그램을 켤 때마다 자동으로 백업합니다. **지금 백업**으로 바로 만들 수도 있습니다.
- **폴더 바꾸기**: 구글드라이브 같은 동기화 폴더를 고르면 PC가 고장 나도 백업이 남습니다.
- **보관 개수**: 이 개수를 넘으면 오래된 백업부터 지웁니다.
- **이 백업으로 되돌리기**: 그 시점 데이터로 돌아갑니다. 되돌리기 직전 상태도 `..._before-restore.db`로 백업되므로 다시 돌아올 수 있습니다.

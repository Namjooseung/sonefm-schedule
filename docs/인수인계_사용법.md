# SoneFM 편성표 — 사용법

이 문서는 개발자가 아닌 분이 프로그램을 쓰고 관리할 수 있도록 적은 안내서입니다. 기능이 추가될 때마다 이어서 적습니다.

## 1. 프로그램 실행

- 바탕화면의 **SoneFM 편성표** 아이콘을 더블클릭합니다. (설치 파일은 마지막 단계에서 만들어집니다.)
- 창 제목이 "SoneFM 편성표"인 창이 뜨면 정상입니다.

## 2. 데이터는 어디에 저장되나요?

프로그램을 지우거나 새 버전으로 다시 설치해도 아래 폴더의 데이터는 그대로 남습니다.

| 무엇 | 위치 |
|---|---|
| 편성 데이터 (파일 하나) | `문서\SoneFM\data\schedule.db` |
| 자동 백업 | `문서\SoneFM\backups\` |
| 오류 기록 (문제가 생겼을 때 개발자에게 보낼 파일) | `문서\SoneFM\logs\app.log` |
| 기본 설정 (데이터 위치·백업 폴더·백업 개수) | `문서\SoneFM\config.json` |

## 3. 자동 백업

- 프로그램을 **켤 때마다** 편성 데이터를 `backups` 폴더에 복사해 둡니다.
  - 파일 이름 예: `schedule_20261103_151908_startup.db` (2026년 11월 3일 15시 19분 08초에 켤 때 만든 백업)
- 최근 **30개**만 남기고 오래된 백업은 자동으로 지웁니다.
- 프로그램이 새 버전으로 바뀌어 데이터 구조를 고칠 때도, 고치기 직전에 따로 백업합니다 (`_before-v2` 같은 이름).
